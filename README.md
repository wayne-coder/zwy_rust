# 账无忧 · 订单消息助手

Windows 桌面工具：读取当前已登录微信 4.x 的本地数据库，按选定的会员与时间段
把聊天消息整理成「注单消息」列表，并在所选时段内**自动追加新消息**。

单文件 exe（约 42 MB），不安装、不写注册表、不上传任何数据。

---

## 运行

直接双击 **`账无忧.exe`**。

- 需要**微信已登录并保持运行**（首次读取要从微信进程内存提取数据库密钥）。
- 首次读取约 3 秒；之后命中 DPAPI 加密的密钥缓存，约 0.3 秒。
- 若微信以管理员身份运行，本程序也需要以管理员身份运行。
- 火绒等安全软件可能提示「读取其他进程内存」——这是提取 SQLCipher 密钥的
  必要操作。程序对微信进程**只读**，不会修改任何微信数据。
- 微信**重新登录会更换数据库密钥**：缓存失效后，请在微信登录状态下重新读取。

## 界面结构

### 主页

- **顶部按钮**：
  1. `选定会员`：进入会员选择页；
  2. `导入注单`：弹窗中用**日历组件**选择日期、用**小时/分钟下拉**选择起止时间，
     确认后回填历史消息；
  3. `清空注单`：按会员清空左侧注单列表。
- **左侧**：常驻「注单消息」列表（没有内容时显示空状态）。
  每行格式：`类型 | 昵称 | 内容（超过 10 个字省略为 …） | 时间（如 2:06）`。
  - 类型：文字 / 图片 / 语音 / 视频 / 表情 / 链接 / 系统 等；
  - 标题右侧有**分组下拉框**：选项为自己新建的会员分组，选中后只显示该分组内
    联系人与群成员的注单消息（「全部分组」显示全部）；过滤只影响显示与复制，
    不影响监控和导入；
  - 支持「复制全部」（制表符分隔，可直接粘贴到 Excel；按当前分组过滤后的列表复制）；
  - 选定会员后实时监控自动开启并常驻，新消息自动追加。
- **右侧**：已选定会员摘要、实时监控状态、最后更新时间。

### 选定会员页

- 与微信通讯录一致的两个 Tab：`联系人` / `群聊`；
- **点击整行即可选择/取消**（勾选圈只作状态指示），选中的行有浅绿色背景；
- 群聊：点击整行 = 选择整群；点击左侧箭头 = 展开/收起成员；
- 展开群聊后点击成员行 = 只选该成员（只取这些成员在该群的消息）；
- **若同时勾选了群聊和成员，以成员选择为准**（只导入所选成员，不会再带入其他成员）；
- 顶部 `← 返回主页` 回到主页，选择结果会保留。

#### 会员分组

- 分组只有**联系人**和**群成员**两个维度，没有「整群」维度。
- 点击顶部「＋ 新建分组」，输入名称即可创建；**新分组默认为空**，支持新建多个、
  名称不能重复。
- 勾选联系人 / 群成员后，点分组的 `加入当前分组`，会用当前选择**覆盖**该分组的
  全部内容（不是追加；整群选择不会加入分组）。
- 每个分组一行，显示 `联系人 N · 群成员 N`，并提供：
  - `加入当前分组`：用当前勾选的联系人 / 群成员覆盖该分组；
  - `仅选本组`：把当前选择替换成该分组的联系人 / 群成员，并自动展开相关群聊，
    树形结构同步显示勾选状态；
  - `成员管理`：弹窗列出该分组的联系人和群成员，可逐条「移除」；移除时树形结构
    里的对应勾选同步取消；
  - `改名`：编辑分组名称（名称不可与其他分组重复，主页下拉框同步更新）；
  - `删除`：删除分组本身（会二次确认），不影响当前会员选择和注单列表。
- 分组保存在 `%LOCALAPPDATA%\WechatViewer\groups.txt`（只记录 username），
  关闭软件或重新读取微信数据后仍然保留。

### 实时监控与导入注单

- **实时监控常驻**：有可读取的会员来源就自动开启。
  - 已新建分组时，监控覆盖**全部分组**的联系人 / 群成员（加上当前勾选的联系人 /
    群成员，整群选择不参与）；同一成员在不同群聊中按 `(群, 成员)` 分别读取。
  - 没有任何分组时，沿用「选定会员」的选择（联系人 / 群聊 / 群成员）。
  - 只有来源为空、或关闭软件，才会停止。
- 监控每 3 秒检查一次微信消息库（文件大小 / 修改时间签名）：
  - 有变化时只增量读取 `sort_seq` 更大的新消息；
  - 按当前选定的会员过滤后追加到左侧列表；
  - 停止前会做最后一轮补拉。
- 监控只追加「从现在开始」的新消息，**不受导入时段限制**；此前的历史消息用
  `导入注单` 回填。
- **导入注单**：用日历选择日期、用小时/分钟下拉选择起止时间
  （默认日期为今天，默认时段 **17:00–21:30**；支持「今天 / 昨天」快捷按钮），
  确认后把所选时段的历史消息载入列表（替换当前列表），监控继续运行。
  - 已新建分组时，导入**全部分组的联系人 / 群成员**（加上当前勾选的联系人 /
    群成员），因此主页下拉框切换到任意分组都能看到数据；
  - 同一成员同时存在于不同群聊时，消息按 `(群聊, 成员)` 区分、互不合并；
  - 没有分组时，沿用「选定会员」的选择（含整群）。

### 清空注单

- 顶部 `清空注单` 打开树形会员选择窗口，默认全部不勾选。
- **不勾选任何会员** → 清空全部注单。
- 勾选联系人 → 清空该联系人会话的全部行；
  勾选群聊 → 清空该群全部行；
  展开群聊后勾选成员 → 只清空该成员在该群的行。
- 清空只影响列表，不影响实时监控；之后的新消息仍会继续追加。

## 原理

1. **定位数据目录**：微信配置
   `%APPDATA%\Tencent\xwechat\config\*.ini` → 常见「文档」目录 → 各盘符根目录，
   找到形如 `D:\xwechat_files\<wxid>_xxxx\db_storage` 的账号目录。
2. **提取密钥**：只读扫描 `Weixin.exe` 内存，定位
   `com.Tencent.WCDB.Config.Cipher` 配置对象，用固定掩码异或解码出
   `x'<32字节密钥 + 16字节salt>'` 字面量。
3. **校验**：用数据库页 1 的 HMAC-SHA512 校验
   （`PBKDF2-HMAC-SHA512(key, salt^0x3a, 2)`），零误报。
4. **解密**：SQLCipher 4（AES-256-CBC，页大小 4096，reserve 80），
   逐页解密所需数据库到临时目录，并合并 `-wal` 增量。
5. **联系人 / 群聊 / 头像**：`contact.db`、`head_image.db`；头像缺失时从
   微信头像 CDN（`wx.qlogo.cn`）补拉，仍取不到则显示首字占位图。
6. **消息**：`message/message_N.db`，表名 `Msg_<md5(会话ID)>`，发送者由分片内
   `Name2Id` 映射；正文可能是 UTF-8、微信容器头 + 明文或 zstd 帧
   （用纯 Rust 的 `ruzstd` 解压）。
7. **隐私**：退出时删除临时目录中的解密明文；密钥仅以 DPAPI（当前 Windows
   用户）加密缓存在 `%LOCALAPPDATA%\WechatViewer\keys.dat`。

## 兼容性

- 实测环境：Windows 10 x64 + 微信 **4.2.0.53**。
- 微信 4.x 各版本数据库结构一致；若某次大版本更新改动了内存锚点，
  密钥提取可能失效（界面会给出提示），需要更新 `src/keyextract.rs` 中的常量。
- 仅支持微信 4.x（3.x 的存储结构完全不同）。

## 构建

需要 Rust GNU 工具链（`x86_64-pc-windows-gnu`）与 MinGW binutils（`dlltool`）。
仓库内的 `tools/msys64` 是便携工具链，仅构建时需要。

PowerShell：

```powershell
$env:PATH = "D:\A-Wayen\project\zwy_rust\tools\msys64\mingw64\bin;$env:USERPROFILE\.cargo\bin;$env:PATH"
cargo build --release
Copy-Item target\release\wechat_viewer.exe "账无忧.exe"

cp target/release/wechat_viewer.exe 账无忧.exe
```

产物：`target\release\wechat_viewer.exe`（静态链接，只依赖 Windows 系统 DLL）。

### 自检 / 调试

```powershell
.\账无忧.exe --selftest
.\账无忧.exe --import-test <会话ID> [日期] [开始时间] [结束时间] [since_sort]
# 例：.\账无忧.exe --import-test 58545017002@chatroom 2026-11-20 19:00 20:00
# 传 since_sort（毫秒）可验证实时监控使用的增量查询
```

不启动界面，摘要写入 `%TEMP%\WechatViewer\selftest.txt` /
`%TEMP%\WechatViewer\import_test.txt`。

环境变量：

| 变量 | 作用 |
| --- | --- |
| `WV_DEBUG=1` | 在标准错误打印各阶段耗时 |
| `WV_NO_LIVE=1` | 跳过内存扫描，仅测试本地密钥缓存路径 |

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `src/main.rs` | 程序入口、窗口、`--selftest` / `--import-test` |
| `src/ui.rs` | 账无忧主页、选定会员页、会员分组、导入弹窗、注单列表 |
| `src/groups.rs` | 会员分组的本地持久化与注单过滤匹配 |
| `src/loader.rs` | 加载编排：定位 → 密钥 → 解密 → 联系人/群聊/头像 |
| `src/messages.rs` | 消息表定位、正文解码、时段过滤、实时增量监控 |
| `src/keyextract.rs` | 从 Weixin.exe 内存提取候选密钥 |
| `src/decrypt.rs` | SQLCipher 页解密、WAL 合并、密钥校验 |
| `src/sqlite.rs` | `winsqlite3.dll` 的极薄封装 |
| `src/locate.rs` | 微信数据目录 / 账号目录定位 |
| `src/cache.rs` | DPAPI 加密的密钥缓存 |
| `src/avatars.rs` | 头像解码与 CDN 补拉（WinHTTP） |
| `src/model.rs` | 数据模型 |

## 已知限制

- 联系人列表不包含公众号与微信内置账号（与微信「通讯录」一致）。
- 少数群没有 `chat_room` 成员表，界面显示「成员列表未同步」，此时只能按整群导入。
- 「注单消息」只显示消息摘要，不下载/展示语音、视频、图片原文件。
- 实时监控依赖微信把新消息写入本地数据库；微信未运行/未登录时不会产生新数据。
- 监控跟随当前会员选择：增减会员后会自动重启监控（只追加此后的新消息），
  不会自动回填新增会员的历史消息；需要历史时请用「导入注单」。

## 说明

本项目只用于读取**本机当前登录账号自己的**微信数据。密钥提取与解密参数
参考了本地 `wechatauto-replica` 项目及公开的微信 4.x 逆向资料，Rust 实现为独立编写。
